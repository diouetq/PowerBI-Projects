La vidéo est publiée sur LinkedIn (et éventuellement YouTube) ; les fichiers `.mp4` / `.mov` de ce dossier sont exclus de Git (taille).

- **Miniature** : `miniature.png` (1280 × 720), à déposer dans ce dossier

Déroulé conseillé (1 min 30 à 2 min) :
1. Le contexte en une phrase : 17,5 millions de licences, 117 fédérations, 2016-2025.
2. Page Portrait : choisir une fédération, la carte et le profil se mettent à jour.
3. Évolution depuis 2019 et lecture à champ constant.
4. Comparer les fédérations puis les territoires (tri, regroupements, mini-courbes).
5. L'assistant : deux ou trois questions en langage naturel.
6. La coulisse : PBIP sous Git, SQL Server, DAX, moteur HTML/JS (ce dépôt).
